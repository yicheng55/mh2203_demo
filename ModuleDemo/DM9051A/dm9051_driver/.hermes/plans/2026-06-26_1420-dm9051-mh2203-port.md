# DM9051 MH2203 Port Implementation Plan

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** 建立 `dm9051_driver/ports/mh2203/` 目錄及其所有驅動檔案，使 DM9051 能夠在 MH2203 控制板上透過 SPI1 運行，風格完全對齊現有 `ports/mh2030a` 結構，並參考 `SDK/dm9051_driver/ports/mh2203` 與 `SDK/src/xx_port/mh2203/spi1/hhal_mh2203_spi1.c` 的實際 SPI 實作。

**Architecture:** 直接在 `ports/mh2030a` 結構下複製並重命名為 `ports/mh2203`，保留分層設計：public header + priv header + polling transport + DMA transport + interrupt + platform/board/delay。所有 SPI1/GPIO 參數沿用 MH2203 實際硬體：PB3 SCK、PB4 MISO、PB5 MOSI、PA15 CS、PF7 RST、PF6 INT。優先提供 polling SPI，再補 DMA/INT 可選檔案。

**Tech Stack:** C (Keil MDK, Cortex-M0/M3 compatible, SPL/StdPeriph), DM9051 HAL vtable, uIP/lwIP adapter。

---

## Context / Assumptions

- 目標 MCU：MH2203，現有 SDK 中已有 `SDK/dm9051_driver/ports/mh2203/` 提供 MH2203 專用 port，但本 repo 尚未移植。
- 參考硬體對映：`SDK/src/xx_port/mh2203/spi1/hhal_mh2203_spi1.c` 顯示 SPI1 需 remap：PB3 SCK、PB4 MISO、PB5 MOSI，PA15 CS，PF7 RST。
- 現有 `ports/mh2030a` 目錄為唯一參考樣板，包含 README.md、platform.h、board.{c,h}、delay.{c,h}、hal_spi1 系列。
- 公開 header 中加入 `DM9051_MH2203_OWN_EXTI9_5_HANDLER`（MH2203 的 INT Pin 是 PF6，EXTI Line6，屬於 EXTI9_5）。
- 新 port 目錄建立後，需同時建立相對應 `examples/uip_mh2203_demo/` smoke test。

---

## Proposed Approach

1. 建立 `ports/mh2203/` 目錄結構，完全對齊 `ports/mh2030a`。
2. 複製 `mh2030a_*` 模板，將所有符號改為 `mh2203`。
3. 內嵌 MH2203 專用 SPI remap/pin mapping，參考 `SDK/src/xx_port/mh2203/spi1/hhal_mh2203_spi1.c` 及 `SDK/dm9051_driver/ports/mh2203/delay`/`int` 命名。
4. 建立 README.md 記錄 port 狀態。
5. 建立 `examples/uip_mh2203_demo/` smoke test。
6. 更新 `docs/plan/BUILD_SELECTION.md` 或等效位置（附加說明，不動現有目標）。

### Task 2: Write polling SPI transport + GPIO/delay/critical sections

**Objective:** 實作 `dm9051_mh2203_spi1.c`，包含 SPI1 remap、CS PA15、RST PF7、polling FIFO 傳輸與 HAL bind。

**Files:**
- Create: `ports/mh2203/dm9051_hal_mh2203_spi1.c`

**Step 1: Write implementation** (`dm9051_hal_mh2203_spi1.c`)

內容可直接對齊現有 `dm9051_hal_mh2030a_spi1.c`，唯一差異在名稱與 SPI remap。要點：

1. vtable `dm9051_mh2203_polling_ops`
2. `dm9051_mh2203_spi1_bus_init_common()`
   - Enable `RCC_APB2Periph_AFIO`
   - Enable GPIOA/GPIOB/GPIOF clocks
     (`RCC_APB2Periph_GPIOA | RCC_APB2Periph_GPIOB |
      RCC_APB2Periph_GPIOF`).
   - Enable SPI1 clock.
   - PA15 push-pull output, default high.
   - PF7 push-pull output.
   - SPI1 remap: disable JTAG pinout and remap SPI1 to PB3/PB4/PB5.
   - PB3/PB5 AF push-pull (SCK/MOSI), PB4 floating input (MISO).
   - SPI mode: master, 8-bit, CPOL Low, CPHA 1 Edge, software NSS,
     baud /4, MSB first.
3. `dm9051_mh2203_reset_gpio_sequence()`: RST low -> Delay_Ms(2) ->
   RST high -> Delay_Ms(10).
4. `dm9051_mh2203_polling_reset()`: bus init + irq init if enabled +
   reset sequence.
5. `dm9051_mh2203_delay_ms()` / `dm9051_mh2203_delay_us()`:
   wrap `Delay_Ms()` / `Delay_Us()`.
6. `dm9051_mh2203_enter_critical()` / `dm9051_mh2203_exit_critical()`:
   PRIMASK.
7. `dm9051_mh2203_polling_read/write_reg/mem()`:
   與 `mh2030a` 相同邏輯，符號改為 `DM9051_MH2203_*`。
8. `dm9051_mh2203_default_config()`: prefilled pins = MH2203 board mapping.
9. `dm9051_mh2203_config_is_valid()`: validate against `DM9051_MH2203_*`
   macros.
10. `dm9051_mh2203_hal_bind()`: validate, copy config, select polling/dma ops.

This directory will contain the MH2203 implementation of the portable

| Signal | Pin |
|--------|-----|

| SCK | PB3 |
